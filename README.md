# IGNITE 2026 🔥 — Where Science Sparks Engineering

Official website and event registration portal for **IGNITE 2026**, the flagship state-level science & innovation fest organized by the **Department of Applied Science and Engineering, TKM Institute of Technology (TKMIT)**, Kollam, Kerala.

![IGNITE 2026 Preview](assets/hero-graphic.jpg)

---

## 🌟 Highlights & Features

- **Collegiate Identity**: Authentic TKM Institute of Technology crest, AICTE approval & APJAKTU affiliation details.
- **Hero Showcase**: Cosmic night-sky atmosphere with glowing flame-bulb branding, cursive tagline, event metadata badges, and artistic floating elements (*Ideate, Explore, Compete, Create*).
- **Two Big Events in One Fest**:
  - **🧠 QUIZ WHIZ V2.0**: State-level science championship featuring rapid-fire rounds and multimedia buzzer stage finale.
  - **🚀 EXPLORA 26**: Project Expo for working models, green technology, IoT/robotics, and everyday scientific solutions.
- **Interactive Registration Hub & Delegate Admit Card**:
  - Multi-step registration flow (School info, Teacher in-charge, Student delegates, and Project domains).
  - Instant generation of verified **Delegate Entry Pass / Admit Card** with unique Registration ID (e.g. `IGN26-QW-1042`), reporting time, and procedurally drawn QR verification code.
  - One-click print/PDF pass export and status lookup tool with local storage persistence.
- **Exciting Cash Prizes**:
  - 🥇 First Prize: **₹ 20,000**
  - 🥈 Second Prize: **₹ 15,000**
  - 🥉 Third Prize: **₹ 10,000**
  - ⭐ Fourth Prize: **₹ 5,000** (For Expo Innovation)
- **Program Schedule**: Detailed 6-stage timeline for November 5, 2026.
- **Why Join & Interactive CTA**: 4 feature highlights and glowing chalkboard rocket launch card.
- **Fully Responsive**: Crafted with modern vanilla CSS for mobile, tablet, and widescreen devices.

## 🚀 Running Locally

No heavy framework or dependencies required.

### Method 1: Built-in Node Server
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Method 2: Direct File Open
Simply open `index.html` in any modern web browser.
